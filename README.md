An open-source visual-first code editor. Build and design Next.js + TailwindCSS apps with AI — edit directly in the browser, see code in real time.

**[Live app](https://onlook.com) · [Docs](https://docs.onlook.com) · [Demo](https://youtu.be/RSX_3EaO5eU?feature=shared) · [Discord](https://discord.gg/hERDfFZCsH)**

## Getting Started

### Designers (Mac)

Two paths — pick the one that suits you:

| | Path | Time |
|---|---|---|
| **Recommended** | [Automated setup](docs/DESIGNER-SETUP-AUTO.md) — one command, walks you through the rest | ~15 min |
| **Manual** | [Step-by-step guide](docs/DESIGNER-SETUP.md) — every step explained | ~30 min |

### Developers

See [docs.onlook.com/developers/running-locally](https://docs.onlook.com/developers/running-locally).

---

## Tech Stack

- **UI** — Next.js, TailwindCSS, tRPC
- **Database** — Supabase, Drizzle ORM
- **AI** — OpenRouter, Morph, Relace
- **Sandbox** — CodeSandbox SDK, Freestyle
- **Runtime** — Bun, Docker
